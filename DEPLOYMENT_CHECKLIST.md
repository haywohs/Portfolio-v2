# Deployment Checklist

## Content accuracy

- [ ] Confirm SAIT completion year.
- [ ] Confirm Wipro / Google Nest employer-client wording.
- [ ] Confirm every project feature is implemented.
- [ ] Confirm every technology listed can be discussed in an interview.
- [ ] Add exact certification titles only after verification.
- [ ] Confirm email, LinkedIn, GitHub, and telephone details in the resume.

## Repository preparation

- [ ] Rename repository clearly, such as `Portfolio-v2` or retain `Portfolio`.
- [ ] Add repository description.
- [ ] Add topics: `portfolio`, `html`, `css`, `javascript`, `qa-engineer`, `software-developer`.
- [ ] Upload the complete folder contents to the repository root.
- [ ] Ensure `.nojekyll` is present.

## Browser testing

- [ ] Desktop Chrome/Edge.
- [ ] Mobile-width browser.
- [ ] Keyboard navigation using Tab and Shift+Tab.
- [ ] Resume opens from the navigation, hero, and contact section.
- [ ] All GitHub and LinkedIn links open correctly.
- [ ] Mobile navigation opens, closes, and responds to Escape.
- [ ] Copy email provides feedback.

## GitHub Pages

- [ ] Settings → Pages → Deploy from a branch.
- [ ] Branch: `main`.
- [ ] Folder: `/ (root)`.
- [ ] Wait for the deployment workflow to complete.
- [ ] Open the published URL in a private/incognito window.

## After publishing

- [ ] Add the live URL to the GitHub profile.
- [ ] Update the resume portfolio URL if the repository name changed.
- [ ] Pin the portfolio repository.
- [ ] Ask one person to test the site without explanation and describe your professional identity after 10 seconds.
